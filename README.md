# 🧠 CSharp Practice Hub

A structured collection of beginner-to-intermediate level C# programming exercises, organized by core programming concepts. Each script demonstrates a specific problem-solving scenario, from simple loops to function-based challenges.

## 📁 Folder Structure

- **Array/**: Array operations like reversing, finding min/max, and averaging
- **Array2/**: Enhanced array logic and value searching
- **foor loop/**: Fundamental problems using `for` loops
- **for loop 2/**: Extended loop exercises (math, strings, digits)
- **If else/**: Conditional logic (discounts, comparisons, ATM)
- **Method/**: Reusable method-based programs (conversion, calculations)
- **while loop/**: Repetitive logic using `while` statements

## 🚀 Skills Practiced

- 🔁 Loops (for, while)
- 🔎 Conditions and comparisons
- 🧮 Math operations
- 🔢 Arrays and string handling
- 🧠 Logical thinking
- 📦 Code organization and modularization
